这是 `kanon-H/homepage` Fork 的 P5 **人工验收模板，不是通过证明**。自动化报告不能代签操作者，也不能证明物理手机、macOS 或你的生产 CDN 已经验证。

使用方式：复制本文记录区到本地受保护、Git/Docker 忽略的目录，例如 `config/p5-baseline/manual-YYYYMMDD.md`，实际执行后填写结果。不要把真实网址、密码、Session、Cookie、Token、未经脱敏的 HAR 或个人信息截图提交到仓库。

功能用法见[多地址导航](../configs/network.md)；精确配置合同与复现命令见仓库根目录 `SPEC.md`、`DEVELOPMENT.md`。

## 验收前

- 使用独立的受控测试实例和虚构导航目标；不要为验收关闭生产认证、Host 校验或 TLS。
- 记录实际源码 commit、工作树是否有改动、构建/镜像标识。只写分支名不足以确定测试版本。
- 准备：有默认/内网/VPN 地址的服务、缺少某模式地址的服务、普通旧服务、书签、带 Widget/统计的服务。
- 至少覆盖没有信息 Widget 的头部，以及实际使用的搜索/时间/天气组合。不要为了测试向第三方发送真实配置或引入生产密钥。
- 目标 OIDC、反代、CDN 测试须先获得明确授权；未提供环境时保持“未执行”，不得猜测结果。

## 场景记录

### M01：原生链接与临时打开

1. 在 default、lan、vpn 中分别使用图标和标题导航，确认两处最终地址一致。
2. 使用中键、当前 OS 的 Ctrl/Cmd 点击，检查原生新标签页确实打开对应模式地址。Linux Ctrl 的结果不能填写为 macOS Cmd 通过。
3. 从服务菜单临时打开另一模式，确认全局模式和刷新后的偏好不变。
4. 选择缺少地址的模式，确认回退原始地址、菜单标记默认来源，并且没有虚假的备用菜单项。
5. 检查服务 `target` 优先于全局 `target`，普通书签不随模式改变。

1. 图标/标题右键出现自定义地址菜单；Shift+右键观察浏览器真正的原生菜单界面。
2. 普通旧服务、卡片空白、Widget、监控/统计区右键不得被自定义菜单接管。

4. 切换模式后检查 Widget/监控仍使用其独立配置目标。需要查看网络请求时，仅在本地核对，不导出带密钥的请求记录。

### M03：键盘、焦点与关闭

1. 用键盘聚焦更多按钮，分别用 Enter、Space、上下方向键打开。
2. 检查菜单方向键循环、Home/End、链接 Enter/Space 和 Escape；Escape 后焦点返回仍存在的触发器。
3. Tab/Shift+Tab 关闭菜单且焦点继续可用，不被全局搜索快捷键抢走。
4. 检查外部点击、页面滚动、窗口改变、模式改变关闭菜单；菜单内部滚动保持打开，同时最多一个菜单。

### M05：剪贴板

1. 安全上下文中允许 Clipboard 权限，确认实际剪贴板内容等于当前地址。
2. 拒绝权限或不支持 API 的浏览器中，确认提示失败、不假报成功、不跳转，之后还能切换模式。

### M06：目标认证、反代与缓存

1. 先记录授权范围及目标链路；使用独立未登录客户端确认首页、服务/书签 API、Next 页面数据不包含导航信息。
2. 登录后访问并重复加载上述入口，再用独立匿名客户端复查，排除共享缓存把登录数据给匿名用户。
3. 退出后重新请求受保护页面和数据入口，确认重新受限。API 可能重定向，也可能返回 401，关键是没有数据泄漏。
4. 核查目标代理/CDN 尊重 `private, no-store`，没有强制忽略 Cache-Control/Set-Cookie。若有共享缓存，另用获准的公开非敏感资源验证缓存链路确实工作；不得公开导航数据来做正对照。
5. 若使用 OIDC，以获准的测试账户验证真实 IdP 登录/回调/退出及 canonical URL/Cookie 行为，不在记录中写账户或 Session 值。
